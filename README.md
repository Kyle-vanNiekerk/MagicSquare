# MagicSquare

This is a simple C++ program for analyzing and working with NxN squares (matrices), originally written as a learning exercise. The program now supports any square size (N), not just 3x3. It provides basic utilities for:

- Drawing an NxN square
- Calculating row and column totals
- Finding unique and missing numbers in the square
- Checking if the square is a magic square
- Calculating the cost to convert a square to a magic square

## Features
- Parameterized square size (change `#define N` in the code)
- Outputs the current state of the square
- Shows which numbers are unique or missing
- Displays the sum of each row and column
- Identifies rows and columns with matching totals
- Checks if the square is a magic square and reports the cost to convert

## How to Run
1. Open the project in Visual Studio or any C++ IDE.
2. Edit the value of `N` and the initial matrix in `main` to experiment with different sizes.
3. Build and run the project.
4. The program will display information about the configured NxN square.
